# eew2nostr 配信アカウント ブランド素材

`config/routing.json` の4アカウントに対応する。配信先は各アカウントとも
Nostr / Bluesky / Concrnt の3系統。

| キー | 表示名 | 対象 | アクセント色 | モチーフ |
|---|---|---|---|---|
| `eew` | 緊急地震速報 | 緊急地震速報 (dmdata) | `#ff2800` 赤 | 震源の ✕ と広がる同心円 |
| `emergency` | 津波・噴火などの速報 | 人命に関わる速報 | `#aa00aa` 紫 | 津波の波と噴火の三角 |
| `warning` | 警報 | 各種警報 | `#ff9900` 橙 | 警告三角と雨・風 |
| `observed` | 観測情報 | 地震情報など観測結果 | `#2f8cff` 青 | 地震計の波形と観測点 |

背景色は全アカウント共通で `#161f24`。アクセント色は viewer の画像API
(`src/publisher/style.ts` の色トークン) と揃えてある。`observed` だけは
警戒レベルの体系に無い色なので、観測＝中立を表す青を新たに割り当てた。

## ファイル

各サイズに PNG 原本と WebP 版を置いてある。

| ファイル | 用途 |
|---|---|
| `<key>-icon-1024.png` | アイコン原寸 (1024×1024) |
| `<key>-icon-400.png` | アイコン縮小版 (400×400) |
| `<key>-cover-1500x500.png` | カバー (1500×500, 3:1) |
| `<key>-*.webp` | 上記それぞれの WebP 版 |

PNG は原本として残してある。SNS のプロフィールにアップロードするときは
PNG / WebP のどちらでもよいが、Web から配信する用途では WebP を使う。

## 各SNSの推奨サイズ

| | アイコン | カバー |
|---|---|---|
| Nostr (kind 0 `picture` / `banner`) | 正方形。クライアント依存だが 400〜1024 で十分 | 3:1 が無難 |
| Bluesky | 正方形 1024 まで、1MB 以下 | 3:1 推奨、1MB 以下 |
| Concrnt | 正方形 | 3:1 |

いずれも 1MB 以下に収まっている。アイコンは円形にトリミングされる前提で
中央に余白を取ってある。

## 生成方法

Codex CLI の `image_gen` (gpt-image-2) で生成し、`sharp` で配信サイズへ整形した。
WebP は PNG から Pillow の `quality=90 / method=6` で変換している。
元画像はアイコン 1254×1254 / カバー 2172×724 で、中央基準の `cover` リサイズで
切り出している。再生成する場合の指示文は `BRIEF.md` と `accounts.json` (同梱)。

**文字は一切入れていない。** 画像生成モデルの日本語描画は崩れるため、
アカウント名は各SNSのプロフィール欄で設定する。
